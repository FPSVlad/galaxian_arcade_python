# Galaxian-like Arcade (Python 3.9)

Небольшая аркада в стиле Galaxian, написанная на Python 3.9 + Pygame.

## Особенности

- Аттракт-режим и стартовый экран в стиле аркадного автомата.
- Система кредитов (`5` = insert coin, `1` = start).
- Игровая петля с волнами врагов, пикированием и стрельбой.
- Очки, жизни, уровни и game over.
- Полностью оригинальные простые векторные/пиксельные ассеты, рисуемые кодом.
- Простые синтезированные звуки (без сторонних аудиофайлов).

## Управление

- `← / →` или `A / D` — движение
- `Space` — огонь
- `5` — вставить монету (добавить кредит)
- `1` — старт игры (тратит 1 кредит)
- `Esc` — выход

## Установка

```bash
python3.9 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python3.9 main.py
```

## Быстрый smoke-тест (headless)

```bash
SDL_VIDEODRIVER=dummy python3.9 main.py --headless --max-frames 120
```
